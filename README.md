# Lily Exam Adventure

เกมฝึกทำข้อสอบเข้า ป.1 สำหรับเด็ก 5-6 ปี แยก Repository จากเกมลิลลี่เดิม (ไม่แชร์โค้ดตอนเล่น ข้อมูลที่บันทึก หรือ cache)

เล่นได้ที่: https://kanasit123-dotcom.github.io/little-exam-adventure/

## เล่นอย่างไร

- **เลือกชุดข้อสอบ** จากการ์ด (บอกว่ายังไม่เคยทำ / กำลังทำ / ทำครบแล้วกี่ครั้งและผลครั้งล่าสุด มีป้าย "ชุดต่อไป") เลือกเพื่อน แล้วทำชุดนั้น — ตอนนี้มี 4 ชุด ชุดละ 12 ข้อ 6 หมวด แบ่ง 3 ช่วง 5 + 5 + 2
- ช่วงทำข้อสอบเหมือนกระดาษข้อสอบจริง: หัวข้อตอน, เรื่องที่ใช้ถามหลายข้อ, ตัวเลือก 1 2 3, มีเสียงอ่านโจทย์และตัวเลือก (ฟังซ้ำได้ไม่จำกัด), เลือก "ยังไม่แน่ใจ" ได้ ไม่มีคำใบ้ ไม่บอกถูกผิด ไม่จับเวลา
- ส่งแต่ละช่วงแล้วดูเฉลย: คำตอบที่ตอบกับคำตอบที่ถูก, คำใบ้, วิธีคิดทีละขั้น (เดินต่อเมื่อเสียงจบ), **ตัวช่วยคิด ตั้งเลข** แบบโลกของลิลลี่ และโจทย์ลองใหม่ที่ไม่เปลี่ยนคะแนนเดิม
- พักระหว่างช่วง (ข้ามได้) จบชุดได้ดาว 1 ดวงและเลือกสติกเกอร์ 1 ชิ้น ไม่ขึ้นกับคะแนน
- หน้าผู้ปกครอง: เปิด/ปิดเสียง, เสียงช้าลง, หน้าจอเรียบง่าย, สรุปคำตอบครั้งแรก การฟังซ้ำ การดูเฉลย และผลโจทย์ลองใหม่
- หยุดกลางคันได้ทุกช่วง ข้อมูลเก็บในเครื่อง (`little-exam-adventure-v1`) กลับมาทำต่อได้

โจทย์แต่งใหม่ตามแนวข้อสอบเก่าที่สถาบันกวดวิชารวบรวม ไม่ใช่ข้อสอบจริงของโรงเรียน และไม่รับรองผลสอบ ([ทะเบียนแหล่งอ้างอิง](docs/RESEARCH.md))

## เพิ่มชุดข้อสอบใหม่

1. คัดลอก `src/content/sets/set-01.js` เป็น `set-02.js` แก้ `id`, `title`, `note` (บรรทัดสั้นบนการ์ด), `stimuli`, `items`, `order`
2. import ใน `src/content/sets/index.js` แล้วใส่ใน `SETS` (ลำดับใน `SETS` = ลำดับการ์ดในหน้าเลือกชุด)
3. ถ้าต้องใช้รูปใหม่: เขียน prompt ใน `design/` ให้ผู้ปกครองสร้างใน Gemini → วางใน `design/incoming/` → ตัดด้วย `design/blobs.py` + `design/cutout.py` → `npm run assets`
4. `npm run voice` (อัดเสียงประโยคใหม่) แล้ว `npm test` — test จะฟ้องถ้าข้อมูลผิดรูปแบบ เฉลยไม่ตรง รูปหาย หรือเสียงไม่ครบ

รูปแบบข้อมูล: [CONTENT-SPEC](docs/CONTENT-SPEC.md)

## คำสั่งสำหรับผู้พัฒนา

~~~bash
npm ci
npm run dev          # http://127.0.0.1:5180
npm run check        # unit tests + build
npm run test:e2e     # Playwright (มือถือ + iPad แบบจำลอง)
npm run voice        # อัดเสียงประโยคใหม่ (ต้องมี Python 3.12 + pip install edge-tts)
npm run assets       # อัปเดต hash รูปใน public/assets/asset-manifest.json
~~~

push เข้า `main` แล้ว GitHub Actions จะทดสอบและ deploy ขึ้น GitHub Pages เอง

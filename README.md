# Lily Exam Adventure

เกมฝึกทำข้อสอบเข้า ป.1 สำหรับเด็ก 5-6 ปี แยก Repository จากเกมลิลลี่เดิม (ไม่แชร์โค้ดตอนเล่น ข้อมูลที่บันทึก หรือ cache)

เล่นได้ที่: https://kanasit123-dotcom.github.io/little-exam-adventure/

## เล่นอย่างไร

- **ชุดจำลองสอบจริง** สุ่ม 30 ข้อจากทุกชุด (หมวดละ 5) และ **ทบทวนข้อที่เคยตอบผิด** (ข้อที่ตอบผิดหรือยังไม่แน่ใจ ตอบถูกแล้วหายจากรายการ)
- **เลือกชุดข้อสอบ** จากการ์ด (บอกว่ายังไม่เคยทำ / กำลังทำ / ทำครบแล้วกี่ครั้งและผลครั้งล่าสุด มีป้าย "ชุดต่อไป") เลือกเพื่อน แล้วทำชุดนั้น — ตอนนี้มี 60 ชุด: ชุด 1–11 ชุดละ 12 ข้อ 6 หมวด แบ่ง 3 ช่วง 5 + 5 + 2; ชุด 12 ขึ้นไปเป็นแบบใหม่ 15 ข้อ 5 + 5 + 5 (เรื่องเดียวถาม 5 ข้อ, แผ่นรูปของใช้, ภาพต่อเนื่อง, ตัวเลือกภาพ 4 ช่อง)
- ช่วงทำข้อสอบเหมือนกระดาษข้อสอบจริง: หัวข้อตอน, เรื่องที่ใช้ถามหลายข้อ, ตัวเลือก 1 2 3, มีเสียงอ่านโจทย์และตัวเลือก (ฟังซ้ำได้ไม่จำกัด), เลือก "ยังไม่แน่ใจ" ได้ ไม่มีคำใบ้ ไม่บอกถูกผิด ไม่จับเวลา
- **กระดาษทด** (ปุ่มดินสอ ✏️ ที่แถบล่าง เฉพาะข้อที่ต้องทดเลข = หมวดคณิตศาสตร์ทุกข้อ + ข้ออื่นที่ต้องบวก/ลบ): เปิดแผ่นเขียนอิสระด้วยนิ้ว Apple Pencil หรือเมาส์ มีปากกา 3 สี ยางลบ ย้อน และล้างทั้งแผ่น (แตะ 2 ครั้ง) แผ่นแสดงโจทย์และรูปตารางไว้ด้านบนให้ดูตอนทด เส้นที่เขียนอยู่ในหน่วยความจำของหน้าเว็บเท่านั้น (ปิดหรือรีเฟรชแล้วหาย) ข้อที่มีรอยเขียนจะมีจุดส้มที่ปุ่ม
- ส่งแต่ละช่วงแล้วดูเฉลย: คำตอบที่ตอบกับคำตอบที่ถูก, คำใบ้, วิธีคิดทีละขั้น (เดินต่อเมื่อเสียงจบ), **ตัวช่วยคิด ตั้งเลข** แบบโลกของลิลลี่ และโจทย์ลองใหม่ที่ไม่เปลี่ยนคะแนนเดิม
- พักระหว่างช่วง (ข้ามได้) จบชุดได้ดาว 1 ดวงและเลือกสติกเกอร์ 1 ชิ้น ไม่ขึ้นกับคะแนน
- **เพื่อนมีลูก**: เลือกเพื่อนตัวเดิมซ้ำจนโตเป็นขนาดใหญ่มาก (4 ครั้ง) แล้วเลือกซ้ำต่อ เพื่อนจะมีไข่ → ไข่ฟักเป็นลูกตัวจิ๋ว → ลูกโตขึ้น แล้วมีลูกคนที่สองอีกรอบ รวม 10 ครั้งต่อเพื่อน 1 ตัว (11 ตัว = 110 ครั้ง) เห็นทั้งในหน้ารางวัลและสมุดสติกเกอร์ ตัวที่ครอบครัวครบแล้วจะพักไว้ให้ดาวไปเพิ่มให้ตัวอื่น จนครบทุกตัวจึงเลือกได้ทุกตัว (รูปลูก: ถ้ายังไม่มีรูปที่วาดให้ เกมใช้รูปแม่ย่อเล็กกับหัวใจ 💗 ไข่เกมวาดเอง — ดู `design/PROMPTS-gemini-13.md`)
- หน้าผู้ปกครอง: เปิด/ปิดเสียง, เสียงช้าลง, หน้าจอเรียบง่าย, สรุปคำตอบครั้งแรก การฟังซ้ำ การดูเฉลย และผลโจทย์ลองใหม่
- หน้าตรวจเฉลยทุกข้อ (จากหน้าผู้ปกครอง): เลือกชุด แล้วอ่านทุกข้อพร้อมเฉลย เหตุผล และข้อลองใหม่ในหน้าเดียว
- โหมดฟังโจทย์แบบสอบจริง (หน้าผู้ปกครอง "การฟังโจทย์ในข้อสอบ" → "แบบสอบจริง 2 รอบ"): เกมอ่านโจทย์พร้อมตัวเลือกให้ฟัง 2 รอบเอง (เรื่องที่ใช้ร่วมกัน 2 รอบก่อนข้อแรก) แล้วฟังซ้ำไม่ได้ เหมือนห้องสอบที่ครูอ่านแค่ 2 รอบ ต้องอ่านตัวหนังสือช่วย; ค่าปกติยังฟังซ้ำได้ไม่จำกัด
- รายงานจุดอ่อน (หน้าผู้ปกครอง "จุดที่ควรฝึกเพิ่ม"): ความแม่นของคำตอบแรกแยกตามหมวดจากชุดล่าสุด (ไม่นับชุดทบทวน) และข้อที่ยังพลาดบ่อย
- หยุดกลางคันได้ทุกช่วง ข้อมูลเก็บในเครื่อง (`little-exam-adventure-v1`) กลับมาทำต่อได้

โจทย์แต่งใหม่ตามแนวข้อสอบเก่าที่สถาบันกวดวิชารวบรวม ไม่ใช่ข้อสอบจริงของโรงเรียน และไม่รับรองผลสอบ ([ทะเบียนแหล่งอ้างอิง](docs/RESEARCH.md))

## เพิ่มชุดข้อสอบใหม่

1. คัดลอก `src/content/sets/set-01.js` เป็น `set-02.js` แก้ `id`, `title`, `note` (บรรทัดสั้นบนการ์ด), `stimuli`, `items`, `order`
2. import ใน `src/content/sets/index.js` แล้วใส่ใน `SETS` (ลำดับใน `SETS` = ลำดับการ์ดในหน้าเลือกชุด)
3. ถ้าต้องใช้รูปใหม่: เขียน prompt ใน `design/` ให้ผู้ปกครองสร้างใน Gemini → วางใน `design/incoming/` → ตัดด้วย `design/blobs.py` + `design/cutout.py` → `npm run assets`
4. `npm run voice` (อัดเสียงประโยคใหม่) แล้ว `npm test` — test จะฟ้องถ้าข้อมูลผิดรูปแบบ เฉลยไม่ตรง รูปหาย หรือเสียงไม่ครบ

รูปแบบข้อมูล: [CONTENT-SPEC](docs/CONTENT-SPEC.md)

ชุดใหม่ 41-50: [เนื้อหา แหล่ง PDF ต้นแบบ และเกณฑ์ตรวจ](docs/SETS-41-50.md) (ยังรอผู้ปกครองอนุมัติเนื้อหาและเสียง)
ชุดใหม่ 51-60: [หัวข้อ แหล่งต้นแบบ ขอบเขตและผลตรวจ](docs/SETS-51-60.md) (ยังรอผู้ปกครองอนุมัติเนื้อหาและเสียง)

## คำสั่งสำหรับผู้พัฒนา

~~~bash
npm ci
npm run dev          # http://127.0.0.1:5180
npm run check        # unit tests + build
npm run test:e2e     # Playwright (มือถือ + iPad แบบจำลอง)
npm run voice        # อัดเสียงประโยคใหม่ (ต้องมี Python 3.12 + pip install edge-tts)
npm run assets       # อัปเดต hash รูปใน public/assets/asset-manifest.json
~~~

push เข้า `main` แล้ว GitHub Actions จะทดสอบและ deploy ขึ้น GitHub Pages เอง

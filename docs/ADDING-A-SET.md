## รูปแบบชุดใหม่ (ชุด 12 ขึ้นไป)

ดูตัวอย่าง `src/content/sets/set-12.js` ถึง `set-14.js` และ `docs/QUESTION-TYPES.md` หัวข้อ "รูปแบบชุด 12 ขึ้นไป"

- 15 ข้อหลัก 3 ช่วง ช่วงละ 5 ข้อ: ช่วง 1 เรื่องเดียวถาม 5 ข้อ / ช่วง 2 แผ่นรูป (`board`) หรือเรื่องที่สองถาม 5 ข้อ / ช่วง 3 ข้อเดี่ยว 5 ข้อ
- ข้อที่ใช้เรื่องเดียวกันต้องอยู่ติดกันใน `order` และไม่เกิน 5 ข้อต่อเรื่อง
- ทุกข้อหลักมีโจทย์ลองใหม่ 1 ข้อ (`type: 'transfer'`, id ลงท้าย `-t`, `skillIds` ต้องเหมือนข้อหลัก)
- ตัวเลือกข้อความมี 3 ตัว; ตัวเลือกที่เป็นภาพล้วน (image/svg ไม่มี text) มีได้ 4 ตัว
- ข้อถูกกระจายตำแหน่ง 1 2 3 (4) ให้ใกล้เคียงกัน; ขั้นเฉลยข้อสุดท้ายจบด้วย "ตอบข้อ N" ให้ตรงตำแหน่ง
- หมวด 6 หมวด (thai, math, reasoning, spatial, science, general) กระจายประมาณ 2–4 ข้อต่อหมวด
- `note` ของชุดไม่เกิน 60 ตัวอักษร
- id ของข้อต้องไม่ซ้ำกับทุกชุด (ข้อสอบจำลองรวมทุกชุด)

## กับดักที่เจอบ่อย

- **เฉลยห้ามหลุดในหน้าข้อสอบ:** `summary`/`hints`/`steps` ต้องไม่เป็นข้อความเดียวกับตัวเลือกหรือโจทย์ (test จะฟ้อง) — เขียน summary ให้ต่างจากตัวเลือก
- **เสียงอ่านตัวเลือกห้ามบอกเฉลย:** ถ้าชื่อภาพตรงกับคำถาม (เช่น ถาม "หมอใช้อะไร" แล้วตัวเลือกชื่อ "หูฟังของหมอ") ให้ใช้ชื่อกลางๆ หรือ `speech: ''`
- ตัวเลือกตัวอักษรไทยเดี่ยว (โจทย์พยัญชนะต้น) ใส่ `speech: ''` เสมอ
- วงแปดช่อง `{ wheel: n }`: 0 = ด้านบน, 1 = บนขวา, 2 = ขวา, 3 = ล่างขวา, 4 = ล่าง, 5 = ล่างซ้าย, 6 = ซ้าย, 7 = บนซ้าย (เวียนตามเข็มนาฬิกา) — ตรวจคำอธิบายทิศในเฉลยให้ตรง
- แผ่นรูป `board` ไม่มีป้ายชื่อ: ข้อความเรื่อง (stimulus text) ต้องอ่านชื่อของทุกชิ้นให้ฟัง
- รูปที่มีในทะเบียนดูได้ที่ `src/core/assets.js` (แผ่น A–G)

## ขั้นตอนเพิ่มชุด

1. เขียน `src/content/sets/set-NN.js` แล้วเพิ่มใน `src/content/sets/index.js` (import + ใส่ใน `SETS`)
2. `node --test tests/*.test.mjs` — ต้องผ่านทุกข้อ ยกเว้น 2 ข้อเรื่องเสียงที่ยังไม่ได้อัด
3. `node scripts/voice-texts.mjs` แล้วอัดเสียงแบบเบื้องหลัง วนจนไม่มีประโยคที่ถูกข้าม:
   `PYTHONIOENCODING=utf-8 python design/voice.py` (รันซ้ำจน log ไม่มีคำว่า `skipped` หรือ `still to re-record`)
   — voice.py อ่านรายการประโยคตอนเริ่มเท่านั้น ถ้าเพิ่มชุดระหว่างอัด ต้องรันใหม่อีกรอบ
   — มักเจอ `NoAudioReceived` (โดนจำกัดความเร็ว) ปล่อยให้ retry เอง ใช้เวลาเป็นชั่วโมงได้
4. `npm run check` และ `npx playwright test` ต้องผ่านหมด
5. อัปเดตเอกสาร: ตาราง "ชุดที่ NN" ใน `docs/RESEARCH.md` (+ บรรทัด "รอผู้ปกครองตรวจ"), จำนวนชุดใน `README.md`, สถานะใน `docs/QUESTION-TYPES.md`
6. Commit บน branch `codex/exam-slice` → `git checkout main && git merge --ff-only codex/exam-slice` → `git push origin main codex/exam-slice` → `git checkout codex/exam-slice`
7. Deploy: `gh workflow run pages.yml --ref main` (push อย่างเดียวไม่ trigger) แล้วรอ `gh run watch <id>`
8. ตรวจบนเว็บจริง https://kanasit123-dotcom.github.io/little-exam-adventure/ ว่ามีการ์ดชุดใหม่ รูปโหลดได้ และ `voice/th/manifest.json` มีจำนวนประโยคครบ
   — ชุดใหม่จะโผล่ในหน้าตรวจเฉลย (สำหรับผู้ปกครอง) เองโดยไม่ต้องแก้โค้ด; ใช้หน้านั้นอ่านเฉลยทั้งชุดอีกรอบก่อนให้ผู้ปกครองตรวจ

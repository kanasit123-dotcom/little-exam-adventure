# ชุดข้อสอบ 51-60

วันที่จัดทำ: 2026-10-04

เพิ่มเฉพาะเนื้อหาใน `little-exam-adventure` ไม่แก้เกมลิลลี่เดิม เกมครัว หรือชุด 1-50
มี 150 ข้อหลักและ 150 ข้อลองใหม่ ชุดละ 15 + 15 ข้อ แบ่ง 5 + 5 + 5
ทุกชุดมีหกหมวด หมวดละ 2-4 ข้อ ใช้การสอบ เฉลย พัก รางวัลและการบันทึกเดิม

## เสียงและการเฉลย

Premwadee เดิม normal -20%, slow -35%, pitch +10Hz, style pause-1
เสียงเรื่อง โจทย์ ตัวเลือก คำใบ้ วิธีคิดและกระดานคณิตศาสตร์แยกตามระบบเดิม
ตัวเลือกภาพและข้อแยกรูปคำอ่านเฉพาะหมายเลข ไม่อ่านชื่อภาพหรือคำที่ช่วยเฉลย
คำอธิบายการอ่านคำและกฎตารางจุดเปิดได้หลังส่งช่วงสอบเท่านั้น
การเรียนข้อลองใหม่ไม่เปลี่ยนคำตอบแรกหรือคะแนนสอบที่บันทึกแล้ว

คละตำแหน่งคำตอบถูกเฉพาะข้อมูลใหม่ 24 ข้อในแปดชุด เพื่อไม่ให้วนตำแหน่งเป็นแพตเทิร์น
ทุกชุดมีคำตอบถูกแต่ละตำแหน่ง 4-6 ครั้ง ไม่แก้ระบบสุ่มหรือ engine
ทวนเรื่องชุด 53 ให้ชัดว่านับเด็กบนรถ และชุด 58 ให้นับน้ำแข็งก่อนเริ่มทดลอง
อัดข้อความที่เปลี่ยนใหม่ทั้งสองความเร็ว และลบเฉพาะคลิป draft ใหม่ที่ไม่ได้ใช้งานแล้ว

## ผลตรวจและสถานะ

- `npm run check`: unit tests 119 ผ่าน และ production build ผ่าน
- Build เตือน bundle ใหญ่กว่า 500 kB; ไม่เปลี่ยนสถาปัตยกรรมในงานเพิ่มชุดนี้
- ชุดใหม่บน mobile/iPad Chromium หลังคละตำแหน่ง: 30 ผ่าน, 10 skip (5.8 นาที)
- 10 skip เป็น fit tests ใน project iPad ที่ตั้งให้วัดเพียงครั้งเดียว; fit ที่รันใน mobile project วัดทั้งสามขนาดจอแล้ว ไม่ใช่การข้ามเพราะมีบัค
- ตรวจทุกข้อหลักที่ 390x664, 768x954, 1024x700 ไม่ล้นจอ
- เล่นทุกช่วงสอบ เฉลย คำใบ้ วิธีคิด กระดาน ข้อลองใหม่ตอบผิดแล้วถูก พักและรางวัล ผ่าน
- ตัวเลือกภาพไม่ซ้อนปุ่มฟัง ตรวจที่ขนาดข้างต้นและ 1280x900
- เปิดตรวจ screenshots ปฏิทิน นาฬิกา แผนที่ ลูกบาศก์ รูปคำและตารางจุด
- รอบตรวจแรกมีบล็อกล้น 76px และ timeout ชุด 59 ขณะเปลี่ยนลำดับเนื้อหา; แก้เฉพาะข้อมูลใหม่แล้วรันซ้ำผ่าน
- Baseline หลังอัดและคละตัวเลือก: โค้ดเดิม 77 ไฟล์และเสียงเดิม 18,200 ไฟล์ hash ตรงทั้งหมด
- ข้อความรวม 11,047 ประโยค จากเดิม 9,100; ไม่มีประโยคเดิมถูกตัดทิ้ง
- อัดเพิ่มสุทธิ 3,894 MP3; รวมคลังสองความเร็ว 22,094 ไฟล์
- ตรวจเสียงที่ชุดใหม่ใช้ 2,173 ข้อความ / 4,346 คลิป (รวมเสียงเดิมใช้ร่วม): browser decode และ nonzero PCM ผ่านทั้งหมด 10 tests (53 วินาที) หลังแก้ข้อมูลสุดท้าย
- ทดสอบ engine เสียงเดิมกับโจทย์น้ำแข็งที่ปรับ: normal/slow ใช้คลิปจริง ไม่ fallback และ promise รอเสียงจบ; ไม่ใช่หลักฐานทดสอบปุ่มไปข้อถัดไปบนอุปกรณ์จริง
- Regression ทั้งเกมก่อนคละตำแหน่งคำตอบ: 268 ผ่าน, 116 skip, ไม่มีล้มเหลว (24.6 นาที)
- ทวนถ้อยคำชุด 53/58: UI 6 ผ่าน, 2 skip และ fit ฟังสองรอบ 2 ผ่าน
- ใช้ config ชั่วคราวในโฟลเดอร์ QA เพื่อชี้ไป preview พอร์ต 5181 ไม่เปลี่ยน config ของ repo

- Fit โหมดฟังสองรอบหลังคละตำแหน่งคำตอบ: ชุดใหม่ 10 ผ่าน (49 วินาที)
- Production preview: เมนู 60 ชุด + 2 โหมดพิเศษ, ชุด 60 เปิดเลือกได้, manifest HTTP 200 และ 11,047 ข้อความ
- `game-lilly` ตรวจ `git status --short` แล้วไม่มีไฟล์เปลี่ยน

ภาพ QA อยู่ที่ `%TEMP%/lily-exam-qa-51-60/new-ui/` และ `final-ui/` เป็นหลักฐานเฉพาะเครื่อง ไม่ใช่ asset เกม

## คำสั่งตรวจซ้ำ

```powershell
npm run check
$config = "$env:TEMP/lily-exam-qa-51-60/preview.config.mjs"
npx playwright test tests/e2e/fit.spec.js tests/e2e/sets-51-60.spec.js --grep 'set-(5[1-9]|60):' --config=$config
$env:VOICE_DECODE = '1'
npx playwright test tests/e2e/voice-51-60.spec.js --project=mobile-chrome --config=$config
Remove-Item Env:VOICE_DECODE
$env:FIT_TWICE = '1'
npx playwright test tests/e2e/fit.spec.js --project=mobile-chrome --grep 'set-(5[1-9]|60):' --config=$config
Remove-Item Env:FIT_TWICE
```

`$config` เป็นไฟล์ QA ชั่วคราวของเครื่องนี้เท่านั้น ชี้ไป production preview 5181 และไม่เริ่ม server
เครื่องอื่นให้ใช้ Playwright config เดิมของ repo กับ dev server หรือสร้าง config QA ของเครื่องนั้น
อย่ารันคำสั่งหลายรอบพร้อมกันโดยใช้ output directory เดียวกัน

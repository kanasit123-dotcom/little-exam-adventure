- เพิ่มไฟล์เนื้อหาสิบชุด และ `authored-pairs.js` ที่ประกอบข้อมูลตาม schema เดิม เฉพาะชุดใหม่
- เพิ่ม import และรายการใน `src/content/sets/index.js` ไม่เปลี่ยนฟังก์ชันของทะเบียน
- เพิ่ม tests และเอกสารนี้ พร้อมอัปเดตจำนวนชุดและทะเบียนอ้างอิง
- เพิ่มรายการข้อความและคลิปเสียงผ่าน `scripts/voice-texts.mjs` และ `design/voice.py` เดิม
- ไม่เปลี่ยน core, screens, review, visuals, CSS, dependency, storage key หรือการย้ายข้อมูล
- ไม่สร้างรูปใหม่ ไม่แก้ทะเบียนภาพ ใช้ artwork ของโปรเจกต์ที่มีอยู่
- ตัวเลือกภาพใช้ `scene: true` ที่ระบบเดิมรองรับ เพื่อเว้นพื้นที่ให้ปุ่มฟังไม่บังรูป ไม่แก้ CSS

## เสียงและเงื่อนไขก่อนใช้งาน

ใช้ Premwadee เสียงเดิม, normal -20%, slow -35%, pitch +10Hz, style pause-1
มีเสียงเรื่อง โจทย์ ตัวเลือก คำใบ้ วิธีคิด และกระดานคณิตศาสตร์
ตัวเลือกเชาวน์ภาพอ่านเฉพาะหมายเลข ไม่อ่านคำบรรยายรูปที่ช่วยเฉลย
โจทย์แบบรูปถามเพียงภาพที่หายไป ไม่บอกกติกาการหมุน การเพิ่มจุด หรือการสลับก่อนส่งคำตอบ
ตารางจุดมีตัวอย่างครบสองคู่ก่อนช่องว่าง ลดความกำกวมระหว่างบวกกับเท่าตัว
โจทย์ที่อ้างป้ายภาพมี speech ชื่อ กอ ขอ คอ งอ แยกจากข้อความที่เห็น
ระบบเดิมยังรอเสียงอัตโนมัติจบก่อนเดินต่อ และการกดฟังใหม่ยังยกเลิกเสียงก่อนหน้า

การอัดเสียงและการมีไฟล์ครบไม่เท่ากับผู้ปกครองฟังอนุมัติ ทุกข้อยังเป็น `draft`
ต้องตรวจคำศัพท์ กลอน จังหวะเสียง ตัวเลข และภาพบน iPad Safari เครื่องจริงก่อนให้เด็กใช้
ไม่ publish หรือ push อัตโนมัติจากการเพิ่มเนื้อหาในรอบนี้

## บันทึกการตรวจรับชุด 41-60 (2026-10-04)

ผู้ดูแลโปรเจกต์อ่านครบทั้ง 600 ข้อ (ข้อหลัก 300 + ข้อลองใหม่ 300) และตรวจเพิ่มด้วยสคริปต์:

- เลขทุกข้อ: 103 ข้อที่มี `review.column` ตรงกับตัวเลือกที่เป็นเฉลย และประโยค "a บวก/ลบ b เท่ากับ c" ในเฉลยคำนวณถูกทั้งหมด

- ข้อความซ้ำกับชุดอื่น: มีเฉพาะประโยคโจทย์กลางๆ เช่น "ภาพในช่อง ? ควรเป็นภาพใด"

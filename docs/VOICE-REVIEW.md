# ตรวจฟังเสียงอ่าน (สำหรับผู้ปกครอง)

เสียงทั้งหมดสร้างด้วย Microsoft Neural TTS `th-TH-PremwadeeNeural` ผ่าน edge-tts (ปกติ rate −20%, ช้าลง rate −35%, pitch +10Hz — ปรับช้าลงตามที่ผู้ปกครองขอ 2026-09-26 เดิม −10% / −30%) และเว้น 0.8 วินาทีระหว่างหัวข้อ เรื่อง และคำถาม
ตกลงกับผู้ใช้แล้ว (2026-09-26): เสียงนี้นับเป็น "เสียงที่ตรวจแล้ว" **เมื่อผู้ปกครองฟังและอนุมัติ** — ตอนนี้ยังไม่ได้ฟังตรวจ

## วิธีตรวจ

1. เปิดเกม ทำชุดที่ 1 ครบทั้ง 3 ช่วง โดยกดฟังโจทย์ ฟังเรื่อง และฟังตัวเลือกทุกข้อ
2. ในหน้าเฉลย เปิด "ดูวิธีคิดทีละขั้น" "คำใบ้" "ตัวช่วยคิด ตั้งเลข" และ "ลองข้อใหม่" ของทุกข้อ
3. ในหน้าผู้ปกครอง เปลี่ยนเป็น "ช้าลง" แล้วฟังซ้ำบางข้อ
4. จดประโยคที่อ่านผิด ออกเสียงแปลก หรือเร็ว/ช้าเกินไป แล้วแจ้งให้แก้ (แก้ข้อความใน `src/content/...` แล้วรัน `npm run voice`)

## ข้อที่ควรฟังเป็นพิเศษ

- ตัวเลขกับหน่วย: "14 ชิ้น", "12 บาท", "13 เมษายน"
- คำว่า "ลูกอ๊อด", "กะเพรา", "ผักบุ้ง", "ทิศตะวันออก"
- ประโยคตั้งเลข: "หลักหน่วย 8 บวก 7 เท่ากับเท่าไร", "2 ลบ 5 ไม่พอ ต้องยืมหนึ่งสิบ แตะเลขหลักสิบ"
- เครื่องหมาย + − = ถูกเปลี่ยนเป็นคำ "บวก ลบ เท่ากับ" ก่อนส่งให้ TTS

## ชุด 41-50 (เพิ่ม 2026-10-04)

ใช้เสียงและค่าความเร็วเดิม ไม่เปลี่ยน engine หรืออัดทับคลิปของชุด 1-40
การตรวจไฟล์ครบและ decode ผ่านไม่ใช่การอนุมัติการออกเสียงจากผู้ปกครอง
ทุกข้อใหม่ยังเป็น `draft`; ผลตรวจทางเทคนิคอยู่ใน `docs/SETS-41-50.md`

- ฟังเรื่องห้องสมุด บทร้อยกรองสวนดอกไม้ และบทความต้นกล้วย ทั้งปกติและช้า
- ฟังวันถัดไป อายุเท่ากัน และโจทย์แถวความสูง โดยเฉพาะคำว่า ก่อน หลัง ระหว่าง และทันที
- ฟังจำนวน หน่วย ราคา เงินทอน และคำอธิบายตัวทด/ตัวยืมในช่วงเฉลย
- ตรวจเสียงชื่อป้าย กอ ขอ คอ งอ ให้ตรงกับภาพเรียงเหตุการณ์
- โจทย์ภาพหายต้องไม่อ่านกติกาหรือคำบรรยายตัวเลือกที่ช่วยบอกคำตอบก่อนส่ง
- บน iPad Safari จริง ตรวจฟังซ้ำ เปลี่ยนความเร็ว หยุด/ทำต่อ และกลับจากการพักหน้าจอ

สถานะ: รอผู้ปกครองฟังอนุมัติและทดสอบ iPad Safari เครื่องจริง ยังไม่ publish

ผลตรวจทางเทคนิคชุด 41-50: 2,068 ข้อความ / 4,136 คลิปสองความเร็ว decode ใน Chromium ได้และไม่เงียบ
ไม่แทนการตรวจความถูกต้องในการออกเสียงโดยผู้ปกครอง

ในงานเพิ่มชุดพบคลิปเดิมว่าง 3 ไฟล์ของชุด 20 และ 35 และคงไว้ตามขอบเขตตอนนั้น
สถานะเมื่อส่งต่อ 2026-10-04: มีงานอื่นซ่อมสามไฟล์แล้ว พร้อมเทสต์ตรวจไฟล์เล็ก; `npm test` ผ่าน 120 รายการ
รายละเอียดชื่อไฟล์และข้อความอยู่ใน `docs/SETS-41-50.md` หัวข้อปัญหาเดิม และ `docs/WORK-CHECKPOINT.md`

## ชุด 51-60

ใช้เสียง ความเร็วและระบบอัดเดิม ไม่อัดทับคลิปของชุด 1-50
ฟังตรวจเรื่อง วันเวลา ชื่อทิศ จำนวน หน่วยและคำอธิบายการทด/ยืมทั้งสองความเร็ว
ข้อแยกรูปคำ เสือ/เสื่อ/เสื้อ และตัวเลือกภาพต้องอ่านเฉพาะหมายเลขระหว่างสอบ
คำอ่านจริงและกฎภาพอยู่เฉพาะในช่วงเฉลย
ผลตรวจทางเทคนิคและจำนวนไฟล์ดู `docs/SETS-51-60.md`
ยังรอผู้ปกครองฟังอนุมัติและทดสอบ iPad Safari เครื่องจริง ไม่ publish ในงานนี้

ผลตรวจทางเทคนิคหลังทวนเนื้อหาและคละตัวเลือก: 2,173 ข้อความ / 4,346 คลิปสองความเร็ว
decode ใน Chromium ได้และมีสัญญาณเสียงทุกคลิป; เพิ่ม MP3 สุทธิ 3,894 ไฟล์
เสียงเดิม 18,200 ไฟล์ hash ตรงตอนจบงานเพิ่มชุด ก่อนมีงานอื่นซ่อมคลิปว่างสามไฟล์
ผลนี้ไม่รวมการอนุมัติการออกเสียงหรือ Safari เครื่องจริง
